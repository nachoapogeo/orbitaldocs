Welcome to the **Orbital Social Media System**. This guide will walk you through setting up your file to create consistent, high-quality social media assets efficiently.

## Setup

1. **Duplicate the template** to your Figma drafts.
2. **Review the "Start Here" page** in the file for a quick tour of the canvas.
3. **Install recommended fonts** (Inter and Geist Mono are used by default).

## Configuring Your Brand

The system uses **Modes** to switch between different brand identities (e.g., your studio's brand vs. your client's brand).

1. Go to the **Variables** panel.
2. Under the **Brand** collection, create a new mode for your client.
3. Input your client's color palette and logo assets.
4. Switch any frame's mode to "Client" to instantly rebrand all assets.

## Workflow Overview

1. **Briefing**: Use the built-in briefing templates to gather requirements.
2. **Proposal**: Design your strategy using the proposal slides.
3. **Production**: Use the carousel and post templates to create content.
4. **Review**: Share the file link for feedback.
5. **Export**: Use the "Export Station" to generate final assets.

## Tips for Success

- **Use Master Components**: Always edit the master component for recurring elements like footers or handles.
- **Check Contrast**: The system automatically checks contrast ratios for accessibility.
- **Keep it Organized**: Use the provided page structure to keep your file clean.
