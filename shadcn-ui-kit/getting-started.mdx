Start using your **Orbital Shadcn UI Kit** by following these simple steps. Whether you are starting a new project or integrating into an existing one, this guide will help you get up and running quickly.

## Prerequisites

Before you begin, ensure you have the following:

- A Figma account (Free or Professional)
- Basic knowledge of Figma variables and auto layout
- The Orbital Shadcn UI Kit file (duplicate from the community or your purchase link)

## Quick Setup

1. **Duplicate the file** to your drafts.
2. **Publish the library** if you plan to use it across multiple files (requires Figma Professional plan).
3. **Enable variables** in your local file to start theming immediately.

## Using the Variable Editor

The kit is powered by the **Orbital Variable Editor**, which allows you to manage your design tokens centrally.

1. Open the **Variables** panel in Figma.
2. Navigate to the **Theme** collection.
3. Adjust your primary colors, radius, and spacing values.
4. Watch as your changes propagate instantly across all components.

## Structure

The file is organized into clear pages to help you navigate:

- **Cover**: Project details and version.
- **Getting Started**: Instructions and quick tips.
- **Components**: The main library of shadcn/ui components.
- **Examples**: Ready-to-use page examples and blocks.
- **Icons**: Lucide icon set integration.
