The **Brandbook Variable Editor** is the central tool for customizing all variable collections inside the file. It allows you to configure, preview, and export settings directly in **Figma JSON** format, ensuring every project perfectly adapts to each client’s brand identity.

## What you can do here

- **Onboarding** → Input client/studio information that propagates across the entire document.
- **Primitives** → Configure base tokens such as sizes, borders, and radii.
- **Typography** → Define font families, weights, and text hierarchies.
- **Spacing** → Adjust margins, columns, paddings, and global spacing values.
- **Proposals** → Manage collections of variables for different design proposals.
- **Export** → Download the configuration as JSON, ready to import into Figma.

### Important note

The editor is optimized for the modular logic of the **Brandbook**, where each variable collection connects directly to typography, layout, color, and illustration components. This ensures that every page of the document responds instantly to changes made in the editor.
